GEO Visibility Dashboard — static export
=========================================

This folder is a production build. Share the ZIP as-is, or upload these files to any static host.

Option A — Quick view locally (recommended)
---------------------------------------------
1. Unzip so you see geo-dashboard.html and an "assets" folder in the same directory.
2. Open Terminal in this folder and run:

     npx --yes serve .

3. In your browser open:

     http://localhost:3000/geo-dashboard.html

   (Port may differ; the terminal will show the URL.)

Option B — Netlify Drop
-----------------------
Drag this entire folder onto https://app.netlify.com/drop then open the site URL + /geo-dashboard.html

Note: Double-clicking the .html file may not work (browsers block local scripts). Use Option A or B.
