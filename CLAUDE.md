# TrustRadius PM Prototyping Environment

## Project Purpose
- Prototyping environment for TrustRadius Product Management team
- Used to create mocks and user experiences for customer feedback
- NOT a production environment - prioritize speed and experimentation
- Focus: rapid iteration and user validation

## Development Approach
- Speed over perfection - prototype quality, not production quality
- Favor quick implementations that demonstrate concepts
- Mock data and simplified backends are acceptable
- Documentation should focus on explaining the prototype's purpose and user flow
- Code quality: readable and functional, not enterprise-grade

## Key Context
- TrustRadius: B2B software review and buyer intelligence platform
- "TR insights for buyers" refers to providing actionable intelligence to software buyers
- Prototypes here test new features and experiences before production investment

## When Working on This Repo
- Ask clarifying questions about the user experience goals
- Suggest quick technical approaches for prototyping
- Don't over-engineer solutions
- Focus on demonstrable user-facing features
